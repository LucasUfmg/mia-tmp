# RedeFlex Insights

Estou construindo um sistema/dashboard chamado RedeFlex. A planilha em anexo contem os dados que quero apresentar no BI. A imagem e um exemplo de como gostaria o layout do BI. As duas primeiras tabelas da planilha devem ser BIGNUMBERS com os valores da REDE de postos, assim como na imagem. As duas ultimas tabelas devem ser graficos de pizza, onde indices sao as categorias e as colunas m/lt, rb, lb devem ser valores apresentados quando o usuario passar o mouse nas categorias do grafico. Crie uma tela para que eu possa apresentar ao investidor. Monte uma tela profissional, atraente, com as informacoes da planilha.
